# Claude Prompt Alpha

Make a game based on the movie Caddyshack: Caddyshack the Game. Parts of the game are side-scrolling adventure game, in the style of of Maniac Mansion. Other parts of the game are top-down golf holes and golf challenges played in the style of Golf Story. The protagonist is a teenage Caddy, like Danny Nonan but a different character. He has the same goals: make money caddying, qualify for the caddy golf tournament and win a college scholarship. You traverse through environments from the movie meeting characters from the movie, solving adventure-game style puzzles. Examples: you have figure how to “pick up that blood” at the caddy shack, help Ty Webb play-through the groundskeepers shed, and assist the groundskeeper’s hunt for the infamous gopher. Adventure game play is interspersed with golf holes and silly golf challenges. The game culminates in a 5-hole caddy golf tournament. If you don’t make the winning score of 24 or 4 over par, the game finishes with the quote, “the world needs ditch-diggers too.” Make it playable on a Windows PC with the keyboard or with a game pad controller.
